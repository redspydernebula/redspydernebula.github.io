Simulation - Finite Element Analysis

Below is a simulation project using a finite element solver. The goal was modeling the behaviour of a physical system under various loads and boundary conditions. This was done by representing the system as a mesh of element tetrahedra, applying forces due to gravity or elastic deformation, and solving for the resulting displacements and stresses.

The project was implemented in C++ and used the Eigen library for linear algebra operations. The results were visualized using OpenGL, allowing for interactive exploration of the system's response to different scenarios.

The video below shows a simulation of a sphere with a low coefficient of stiffness. Despite the near inversion of the tetrahedra, the system remains stable and does not collapse. The second video shows a simulation of an ellipsoid with a higher coefficient of stiffness bounding off a collider.

Computational Photography - Splat Morphing

Below is a computational photography project focused on splat morphing. The goal was to create a system that could generate smooth transitions between images by representing them as splats and interpolating their positions and colors over time. This involved utilizing algorithms for splat generation, morphing, and rendering, as well as implementing a user interface for exploration of the results. The project was implemented in python, with a pipeline for processing images, to structure-from-motion, to gaussian splat generation, and finally to morphing with two different methods. The first was a simple linear interpolation, while the second utilized a more sophisticated approach based on spherical harmonics.

The video below shows a morphing of two images using the spherical harmonics method. The results demonstrate the effectiveness of the approach in generating smooth and visually appealing transitions between images.

Computer Security - StackSwap

StackSwap is a security project designed to thward traditional JIT-ROP attacks by implementing a return address swapping mechanism. The project was implemented in C, with a focus on performance and security. The project focuses on hiding the return addresses of functions on the stack to prevent exploitation. To do this, I instrument the prologue and epilogue of each function to swap the stack pointer between an information hiding region before and after the function call. In this case, register r11 was used to move the swapped stack pointer. In testing, little to no gadgets with access to r11 were found.

OMatch! - Basketball Matchmaking Service

OMatch! is a platform dedicated to creating fun and competitive 5 v 5 basketball games at the Brown's OMAC. The service utilizes a matchmaking algorithm that takes into account player statistics, skill ratings, and availability to create balanced teams for each game. The project was implemented as a web application using HTML, CSS, and JavaScript, with a backend server written in Java handling user authentication, data storage with firebase, and matchmaking logic.

The frontend interface allows users to create persistent profiles to store their information such as name, basketball position, and keep track of win-loss records, and find 5 v 5 matches with people of similar skill levels to them based on ELO rating and matchmaking algorithms on the backend. Through this, we hope that students and community members in Providence will be enabled to have optimized, fun games that they can plan out ahead of time with players that are less intimidating because of similar skill levels.
